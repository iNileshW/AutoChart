Graduation project

AutoChart

A chatbot that tells UKHO customers whether their paper chart is out of date.

FastAPI React MCP Geopandas Leaflet

Problem

UK boat owners have no way to know their chart is stale

  • UKHO publishes new editions as coasts, wrecks, buoys and depths change — real ocean demographics keep shifting.
  • Fishermen and leisure sailors currently rely on the shop or word of mouth to decide when to reprint.
  • A wrong decision means either wasted money or unsafe navigation on outdated soundings.

Backend

REST + MCP sharing one service layer

REST

  • POST /api/v1/lookup — chart number / name / title / panel id
  • POST /api/v1/chat — chatbot with intent inference
  • GET /api/v1/data — GeoJSON for the map
  • POST /api/v1/overlap — matplotlib PNG
  • POST /api/v1/overlap-geojson — intersection polygons

MCP tools JSON-RPC 2.0

  • chart.answer — prose reply for the Agent Chat UI
  • chart.lookup
  • chart.overlap / chart.overlap_geojson
  • chart.get_data / chart.list_panels
  • chart.compare — alias for compatibility

Frontend

Two views for two audiences

Home

  • Chatbot: mode + value ⇒ REST lookup
  • Leaflet map (react-leaflet, lazy-loaded)
  • Old panels (navy) • new panels (orange)
  • Green old ∩ new overlay computed on demand
  • Fits map bounds to the matched region

Agent Chatbot

  • Natural-language box: “2345”, “Looe”, “panel 0147_6”
  • Calls chart.answer over MCP
  • Response is prose, not JSON
  • Grounded in the same service layer as REST

Why it matters

A beacon for UK waters

AutoChart chatbot will act as a beacon for UKHO customers — mainly UK-waters fishermen and boat owners — to make the key decision of whether to buy a new paper chart for their navigation, because the charts get changed as per the changing ocean demographics and developments.

Concrete benefits

For customers, UKHO, and the wider ecosystem

Customers

  • Zero paperwork — ask by chart number or place name.
  • Visual confirmation on a live map: matched panels + overlap.
  • Prose reply, no spreadsheet lookup.

UKHO + operators

  • MCP endpoint lets AI agents surface chart currency inside third-party tools without new integrations.
  • Metrics + traces + logs mean the service can be run under an SLO.
  • Docker + CI make redeploy a one-liner.
